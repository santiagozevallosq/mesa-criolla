# Mesa Criolla

Landing page en HTML, CSS y JavaScript para presentar el piloto de comida criolla casera preparada en la cocina del cliente.

## Ver el sitio

Abre `index.html` en un navegador o sirve la carpeta con un servidor local, por ejemplo Live Server en VS Code.

## Archivos principales

- `index.html`: contenido y estructura accesible de la página.
- `styles.css`: estilos adaptables a móvil y escritorio.
- `script.js`: menú móvil y formulario de consulta que prepara un mensaje para WhatsApp.
- `assets/`: fotografías de referencia para el hero y los platos.
- `PLAN-MVP.md`: alcance y planteamiento del piloto.
- `ESCALAMIENTO-PROYECTO.md`: investigación sobre autenticación, pedidos y pagos.

## WhatsApp

El formulario está conectado a `+51 934 086 161`. Al enviarlo, abre WhatsApp con un mensaje prellenado. El sitio no almacena pedidos ni información de usuarios y no procesa pagos.

## Antes de publicar

Confirmar zona de atención, menú y disponibilidad reales, porciones, precios, condiciones de reserva y derechos de uso de imágenes. Las fotos de los platos están identificadas en la web como referenciales.
